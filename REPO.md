# Scriptural — repo notes

GitHub: `https://github.com/kenhara/omarchy-scriptural`

Verse of the day. Pause. Unofficial Midvash VOTD for Omarchy.
Named for the familiar scriptural prayer line — not affiliated with Midvash or any Bible publisher.

```sh
omarchy plugin add https://github.com/kenhara/omarchy-scriptural.git --enable
omarchy bar move harris.scriptural --section right
```

Cache (optional cleanup after remove): `~/.cache/scriptural/`.
