# Daily Bread — repo notes

GitHub: `https://github.com/kenhara/omarchy-daily-bread`

Verse of the day. Pause. Unofficial Midvash VOTD for Omarchy.
Named for the familiar daily-bread prayer line — not affiliated with Midvash or any Bible publisher.

```sh
omarchy plugin add https://github.com/kenhara/omarchy-daily-bread.git --enable
omarchy bar move harris.daily-bread --section right
```

Cache (optional cleanup after remove): `~/.cache/daily-bread/`.
